WEEK 2 – FOOTPRINTING AND NETWORK SCANNING

Project Overview

This folder contains documentation and practical work completed during Week 2 of the Networkwalks Cybersecurity Internship.

The exercises focused on information gathering, footprinting techniques, and network scanning using different cybersecurity tools in a controlled learning environment.

Modules Completed

1. W2-PM1 – Footprinting with Multiple Kali Linux Tools

Practical exploration of six Kali Linux tools used for footprinting and information gathering.

2. W2-PM3 – Maltego-Based Footprinting

Using Maltego to explore relationships between publicly available information and digital assets.

3. W2-PM4 – theHarvester-Based Footprinting

Using theHarvester to gather publicly available information relevant to a target.

4. W2-PM5 – Zenmap-Based Network Scanning

Using Zenmap to perform network scanning and examine discovered hosts, open ports, and services.

Final Deliverable

A detailed report covering the selected and completed modules, including the methodology, tools used, observations, results, and relevant screenshots.

Disclaimer

All activities were conducted for educational purposes within the scope of the internship. Information gathering and scanning activities were performed in accordance with the applicable authorization and learning guidelines.
